# 📋 Management App

A simple and responsive Project Management application built with **React**, **Vite**, and **Tailwind CSS**. The app allows users to create, manage, and delete projects through a clean and intuitive interface.

## ⚙ Installation

Clone the repository:

```bash
git clone https://github.com/amar-omar/Management-App.git
```

Go to the project folder:

```bash
cd Management-App
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
